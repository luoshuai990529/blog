# 你不知道的大模型训练：原理、路径与新实践

> 原文：[Tw93：你不知道的大模型训练：原理、路径与新实践](https://x.com/HiTw93/status/2040047268221608281)

## 一句话总纲

今天的大模型不是靠一次预训练“炼成”的，而是数据、系统、预训练、后训练、评测奖励、Agent 环境、蒸馏和部署共同组成的持续反馈系统。

## 核心结论

1. **用户感受到的是整条训练链路的结果。** 模型突然变强通常不是单一算法突破，而是后训练、评测、奖励、Agent 训练和蒸馏等环节一起优化到位。

2. **预训练只负责打底。** 它用下一个 token 预测学习语言分布、压缩知识并形成可迁移的基础能力，但不会自动得到好用、可靠的助手。

3. **模型不是参数越多越好。** 在固定算力下，参数量、训练 token 数和计算预算必须匹配；许多模型的问题不是规模太小，而是没有训练充分。

4. **Tokenizer 是长期成本决策。** 词表和分词策略会持续影响中文、代码、数学、多语言能力、上下文利用率和每一次推理的成本。

5. **数据配方比数据总量更重要。** 原始数据必须经过抽取、识别、过滤、去重、隐私与安全处理，再按质量和领域合理混合，才能决定模型最终擅长什么。

6. **训练首先是分布式系统工程。** GPU、显存带宽、并行策略、容错和成本从一开始就限制了模型规模、上下文长度与可用训练方法。

7. **MoE 是效果、容量和成本的折中。** 它用稀疏激活扩大总参数并控制单 token 计算量，但会换来路由、负载均衡和基础设施复杂度。

8. **同规模模型的差距藏在训练细节里。** 超参数迁移、学习率调度、最佳 batch size 和数据参数配比，往往比表面的参数量更能决定训练质量。

9. **长上下文和多模态不是简单加功能。** 它们会同时改变注意力成本、数据编排、batch size、并行方式、数据混合和安全评测。

10. **后训练决定模型是否“会用”。** 预训练提供能力上限，指令微调、偏好优化和强化学习负责把能力激活并约束成用户需要的行为。

11. **SFT 的价值是建立正确起点。** 少量高质量示范先教会模型指令格式、推理表达和基本行为，再让强化学习从可控状态开始探索。

12. **可验证任务最适合强化学习。** 数学、代码和逻辑任务能用程序检查答案，把模糊偏好变成稳定奖励，因此更容易练出可靠推理能力。

13. **GRPO 用组内比较降低 RL 工程负担。** 它对同一问题采样多个回答并相对排序，不需要额外维护价值网络，因此更适合大模型训练。

14. **RL 和 SFT 应形成循环。** RL 探索出的成功轨迹经过拒绝采样变成新的高质量 SFT 数据，再用于下一轮能力收敛。

15. **完整后训练是相互依赖的流水线。** 冷启动保证 RL 能稳定开始，RL 发现好轨迹，拒绝采样沉淀数据，最终对齐让行为达到发布标准。

16. **Grader 实际上定义了模型追求什么。** 只看最终答案、评分过粗或评测失真，都会让模型学会走捷径；榜单提升不等于真实任务变好。

17. **奖励设计必须防止被钻空子。** 强化学习会放大评分器的漏洞，因此评测既要看结果，也要检查过程、泛化、安全性和真实任务表现。

18. **对齐不是训练结束后的补丁。** 系统测什么、如何评分、奖励什么，模型就会朝什么方向优化；安全原则必须进入训练目标和推理过程。

19. **AI 反馈正在减少逐条人工标注。** Constitutional AI 和审慎对齐的共同方向，是让模型依据明确原则自我检查，并把安全判断内化为训练与推理能力。

20. **Agent 训练的核心从数据变成环境。** SFT 时代重视样本多样性，Agent 时代更重视环境的真实性、稳定性、覆盖度、难度、反馈质量和抗利用性。

21. **Agent 要按完整任务而不是单题评测。** 真正目标是在多步工具调用和环境反馈中持续可靠，传统 CoT benchmark 无法覆盖这种能力。

22. **Harness 本身也可以被训练和优化。** 工具、提示、状态管理和执行框架不再只是固定外壳，而能进入外循环搜索，和模型一起提升。

23. **多 Agent 训练应先解决信用分配。** 与其同时优化所有子 Agent，不如先训练负责规划和编排的 orchestrator，把奖励归因收束到可控层。

24. **训练在模型发布后仍然继续。** 生产流量回流数据工程，离线评测反馈训练，更强模型继续生成下一代模型所需的数据，形成持续迭代闭环。

25. **蒸馏的本质是能力迁移和解耦。** 大模型先把推理能力练出来，再把高质量轨迹教给小模型，使小模型不必同时承担海量知识记忆和能力发现。

26. **训练终点不一定是更大的模型。** 真实产品常常更看重成本、延迟、稳定性和专用能力，因此结果可能是更小、更便宜、更可控的模型。

27. **上线版本是产品选择，不是最高分 checkpoint。** 发布前需要综合真实任务、拒答风格、工具稳定性、成本和回归风险，而不是只看单项指标。

## 我自己的最终理解

理解大模型训练，不能只盯着模型结构和预训练规模，而要把它看成一个围绕真实任务不断生产数据、定义奖励、验证行为、迁移能力并回收反馈的工程闭环；真正的竞争力，是让这条闭环比别人转得更准、更稳、更快。
