# RAG 技术链路与专题索引

这个目录用于沉淀我对 RAG 工程链路的专题学习笔记。

每篇文章尽量只解决一个具体问题：文档解析、OCR、表格处理、分块、Query 优化、检索引擎选型、混合检索、索引调优等。不同文章之间的关系统一放在这个 README 中维护，避免每篇文档重复解释“和其他文档的关系”。

## 一、整体链路

可以把当前 RAG 文章按下面这条链路理解：

```text
原始资料
  → 文档接入与复杂内容解析
  → OCR / 图片 / 表格结构化
  → 自动化预处理流水线
  → 文本分块与语义切片
  → 检索前 Query 优化
  → 检索引擎选型
  → 混合检索与多阶段召回
  → 召回结果融合与重排序
  → 索引调优与压缩
  → 术语词库与检索一致性
  → 生成、评估与持续优化
```

## 四、后续维护规则

后续新增 RAG 专题文章时，优先维护这个 README：

- 新文章只关注自己的技术主题，不再重复写大段“和其他文档的关系”。
- 如果需要说明链路位置，可以在文章中用一句话指向本索引。
- 如果一个资料只是已有专题的小补充，优先补充到已有文章，不单独新开文档。
- 如果一个资料有独立的问题背景、解决方案、工程难点和复用价值，再新开专题文档。
